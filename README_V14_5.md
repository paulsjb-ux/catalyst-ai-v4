# Catalyst AI v14.5.0 — Release Candidate

v14.5 turns the validated swing-trading workstation into a release-candidate product shell.

## New in v14.5
- Persistent daily routine audit history across app restarts/cloud persistence.
- Persistent recommendation lifecycle with automatic 3-trading-day expiry.
- New primary **Portfolio** workspace with paper portfolio, live-from-latest-run P/L, equity curve and performance evidence.
- Win rate, expectancy, profit factor and drawdown surfaced in one release-candidate dashboard.
- One-click full trade-history CSV and release-candidate PDF exports.
- Additional iPhone/mobile hardening for metrics, tables and download controls.

No broker execution is added: Portfolio remains a paper/validation portfolio by design.
