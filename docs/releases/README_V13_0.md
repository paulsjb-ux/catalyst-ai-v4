# Catalyst AI v13.0 — Single-Screen Trading Workstation

A compact executive workspace focused on the daily decision rather than page chrome.

## Interface changes
- Streamlit development chrome is hidden.
- Sidebar reduced to 218 px with compact navigation controls.
- Status information is presented in a single 40 px toolbar.
- The run command is the visual focus without creating unnecessary scrolling.
- Today's verdict appears before supporting metrics.
- Metric cards, result tables and page headers have been compressed.
- Daily trading and validation logic is unchanged from v12.0.
