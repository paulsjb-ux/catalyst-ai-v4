# Catalyst AI v14.3.1 — Mobile Navigation Fix

This patch keeps all v14.3 trading and automatic-validation logic unchanged.

## Mobile changes

- Adds an always-visible, sticky page selector on iPhone and other narrow screens.
- Keeps the desktop left navigation rail unchanged.
- Hides the inaccessible Streamlit sidebar on mobile.
- Makes the Daily Routine primary action full-width.
- Tightens mobile spacing, status cards, metrics and table overflow.
- Preserves Daily Routine as the default page.

## Daily use on iPhone

1. Open Catalyst AI.
2. Use the selector at the top to move between pages.
3. Select **Daily Routine** and press **Run Daily Routine**.
4. Use **Validation** from the same selector to review the 30-day programme.
