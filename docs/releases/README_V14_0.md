# Catalyst AI v14.0 — Adaptive Performance Engine

v14 freezes the v13 workstation UI and focuses on measurable strategy quality.

## Added
- Walk-forward adaptive confidence with no future leakage.
- Weighted evidence: recent 40%, historical 20%, regime 20%, score band 10%, ticker 10%.
- Dynamic HIGH / MEDIUM / LOW / BLOCK confidence and reduced position sizing.
- Ticker, score-band and regime quality update from completed trades.
- Holding-period diagnostics for 1–5, 6–10, 11–20, 21–40 and 40+ day swings.
- Validation report breakdown by adaptive confidence and holding period.
- v14 portfolio-return field for like-for-like backtest comparison.

## Important
v14 does not claim improved profitability until a fresh backtest and validation report prove it. The feature is an evidence engine, not a guarantee of returns.
