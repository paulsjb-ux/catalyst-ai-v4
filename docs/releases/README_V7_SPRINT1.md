# Catalyst AI v7.0 — Sprint 1

## Autonomous Daily Routine

The new **🚀 Run Daily Routine** page performs the complete morning workflow:

1. Build the expanded liquid-market universe.
2. Download current market history.
3. Detect the SPY/QQQ market regime.
4. Score the universe.
5. Generate target, stop and risk/reward plans.
6. Generate the Daily Intelligence Brief.
7. Refresh configured alerts.
8. Write CSV, Markdown and JSON exports.

The page includes live progress, stage-level results, duplicate-run protection, a saved last-run timestamp and a final operational summary.
