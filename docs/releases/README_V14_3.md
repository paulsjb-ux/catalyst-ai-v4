# Catalyst AI v14.3 — Automatic 30-Day Validation

- Every successful Daily Routine run is recorded once per UTC trading date.
- Up to two qualified swing recommendations are added to an automatic paper-validation ledger.
- Existing paper positions are marked from the latest scan price and closed when the close-only mark reaches target or stop.
- Validation progress, open/closed trades, win rate, profit factor and cumulative return are shown on Daily Routine and Validation pages.
- Evidence can be downloaded as JSON and the programme can be reset explicitly.
- No broker orders are placed. The tracker is evidence collection, not live execution.
