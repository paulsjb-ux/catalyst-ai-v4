# Catalyst AI v11.0 — Executive Workspace

This release reorganises Catalyst around the user's daily workflow.

- Five primary daily destinations: Daily Routine, Today's Decision, Dashboard, Watchlist, Reports.
- Specialist functions are retained under a compact More tools panel.
- Large repeated branding cards are replaced with compact page headers.
- Daily Routine remains the default landing page and one-button workflow.
- Trading logic is unchanged from v10.1.
